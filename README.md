# LEGENDS FITNESS CENTRE — Premium 3D Cinematic Gym Website

A high-performance, agency-grade 3D gym web application built with **Next.js 14, React Three Fiber, Three.js, GSAP ScrollTrigger, Lenis Smooth Scroll, and Tailwind CSS**.

![LEGENDS FITNESS CENTRE](public/images/hero-athlete.png)

---

## ⚡ Features & Technology Stack

- **Framework**: Next.js 14 (App Router), React 18, TypeScript
- **3D Graphics & Canvas**: React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`), HTML Canvas Sequence
- **Animations & Smooth Scroll**: GSAP, GSAP ScrollTrigger, Lenis Smooth Scroll, Framer Motion
- **Styling**: Tailwind CSS, Inter Font (Weights 500-600), Custom Glassmorphism Theme (`#18242a`, `#1f2d35`, `#38bdf8`)
- **Interactive Features**:
  - 300-Frame Scroll-Controlled Canvas Video Sequence Hero
  - Biomechanical 3D Equipment Showcase (Procedural 3D Models)
  - Interactive WhatsApp CTA Direct Booking (`+91 870 043 4450`)
  - Live Google Maps Location Pin & Directions (`https://maps.app.goo.gl/azc84kzYwWKyEaVB8`)
  - Integrated Background Gym Motivation Audio Player with Animated Visualizer
  - Official Instagram Profile (`@legends_21_fitness`) Integration
  - Transparent Monthly Membership (₹1,399 / Month)
  - 6 Days Open Schedule (Mon - Sat: 5:00 AM - 11:00 PM | Sun: Closed)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/satyamp11/gym-project.git

# Navigate to project directory
cd gym-project

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
